How it Works (Recursion)

The Tower of Hanoi is a classic mathematical puzzle that elegantly demonstrates the power of recursive algorithms.

void hanoi(int n, char source, char aux, char target) {
    if (n == 1) {
        printf("Move disk 1 from %c to %c\n", source, target);
        return;
    }
    // 1. Move n-1 disks from Source to Auxiliary
    hanoi(n - 1, source, target, aux);
    
    // 2. Move the nth disk from Source to Target
    printf("Move disk %d from %c to %c\n", n, source, target);
    
    // 3. Move n-1 disks from Auxiliary to Target
    hanoi(n - 1, aux, source, target);
}
